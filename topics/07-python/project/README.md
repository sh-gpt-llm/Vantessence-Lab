# Python capstone

**Status:** Not started — begin after L1 foundations are complete.

Build a small, documented Python solution to a practical enterprise or product
problem. Choose the problem with the learner during L3; examples include
validating a service inventory or summarizing product feedback.

The published portfolio piece should include:

- A concise problem statement and intended user.
- A working implementation and automated checks.
- Setup and usage instructions.
- Design choices, trade-offs, and limitations.
- A short case study describing the outcome and next steps.
