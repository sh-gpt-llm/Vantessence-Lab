# Vantessence-Lab

**Learn it. Build it. Own it.**

Vantessence-Lab is a proof-led learning system for building the skills to lead
AI-era enterprise and digital transformation. Each topic progresses through
five levels: Foundations, Guided practice, Build, Teach, and Mastery. Advance
only when the level's evidence and “Done when” checklist are complete.

## Start here

- [`plan.md`](plan.md) — track status, topic roadmaps, and evidence gates.
- [`teach.md`](teach.md) — coaching rules, session format, and learner commands.
- [`retro.md`](retro.md) — session reflection and weak-spot log.
- [`topics/07-python/`](topics/07-python/) — active topic: Python L1, Session 02
  (dictionaries).
- [`journal/2026-10.md`](journal/2026-10.md) — current month's learning journal.

## Learning tracks

1. **Architecture:** Enterprise Architecture, TOGAF Foundation and Practitioner,
   ArchiMate, solution and integration architecture.
2. **Strategy and transformation:** strategy and consulting, business,
   technology and digital transformation, operating models, business cases, and
   value realization.
3. **Innovation:** innovation management, emerging-technology scanning and
   evaluation.
4. **AI and data:** AI, ML, Generative AI, prompt engineering, RAG, AI agents and
   orchestration, MLOps/LLMOps, responsible AI, and governance.
5. **Product:** AI product management, product strategy, roadmapping, discovery,
   and metrics.
6. **Cloud:** cloud fundamentals, Azure/AWS architecture, cloud-native, DevOps,
   and FinOps.
7. **Engineering:** Python, SQL, HTML, CSS, JavaScript, React, APIs, and Git.
8. **Forward Deployed Engineering (FDE):** taking AI solutions from client
   problem framing through production rollout.

## Repository structure

```text
plan.md
teach.md
retro.md
journal/
  YYYY-MM.md
topics/
  NN-topic/
    plan.md
    teach.md
    retro.md
    notes/
    exercises/
    project/
```

Every learning session should produce evidence and finish with a Git commit.
Use the current topic's `plan.md` to record proof and update its level only
after its completion checklist is satisfied.
