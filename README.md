Shailesh Kumar's learning-in-public system for growing into AI-era enterprise transformation leadership.

## How I learn

Daily Git loop: `pull → add → commit → push`

```bash
git pull
git add .
git commit -m "Python L1 S01: f-strings format numbers with :,.2f"
git push
```

Commit format: `<Topic> L<n> S<nn>: <what I learned>`
